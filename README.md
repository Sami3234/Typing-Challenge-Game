# KeyQuest - Typing Challenge Game

A responsive Bootstrap 5 typing game built from the Lab Mid requirements. It includes two complete modes:

- **Bubble Burst:** type rising letters before six bubbles escape.
- **Key Magnet:** match target keys while tracking accuracy and response time.

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Select Easy, Medium, or Hard on the home screen.
- Use the physical keyboard during gameplay.
- Start begins a session, Restart clears all state and starts again, and Reset returns home.

Bootstrap and Bootstrap Icons load from jsDelivr, so an internet connection is required for their CDN assets.
